# Birthday Neon Website

## Files
- index.html
- style.css
- script.js
- images/1.jpg
- images/2.jpg
- images/3.jpg
- images/4.jpg
- images/5.jpg
- images/final.jpg

## How to use your own photos

Put your photos inside the `images` folder and rename them:

1.jpg
2.jpg
3.jpg
4.jpg
5.jpg
final.jpg

You do NOT need to change the HTML or JavaScript.

## Run
Simply double-click `index.html` and open it in Chrome/Edge.

The page automatically plays:
1 → 2 → 3 → HAPPY → BIRTHDAY → TO MY → LOVE → photo slideshow → final image.
